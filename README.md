# Nature & Aventure

Mini-projet Web FIA3 - ISSAT Sousse - A.U. 2025/2026
Sujet 6 : Mini magazine en ligne

## Description

Magazine en ligne sur le camping, la randonnée et les voyages nature.

Partie JavaScript :

- navigation entre les articles sans rechargement (fetch local) ;
- carrousel d'images « À la Une » ;
- formulaire newsletter validé avant l'envoi ;
- likes sur les articles, sauvegardés avec localStorage ;
- bonus : menu qui disparaît au scroll et témoignages automatiques.

## Fichiers

- `index.html` : page d'accueil
- `style.css` : feuille de style commune
- `script.js` : partie JavaScript
- `pages/` : les six articles
- `images/` : les photos

## Lancer le projet

Ouvrir le dossier dans VS Code et lancer **Live Server** : `fetch` a besoin d'un serveur local.
Sans serveur, les liens ouvrent simplement les pages d'articles.
